# 文档模板

尖括号里的内容按实际情况替换。模板用中文写；用户用别的语言时，结构不变、换成那种语言。

目录：
1. README.md（学习计划与索引）
2. NN-0 总览（新开阶段时只搭框架）
3. NN-M 精读分篇
4. figs/README.md

写法提醒：

- 句子短、具体。一段只讲一件事。
- 先给结论或问题，再给证据。
- 读者没见过的术语第一次出现时用一句话解释。
- 引用的行号以当前检出的版本为准；README 速览里记下勘察时的 commit（`git rev-parse --short HEAD`），以后代码更新时读者知道行号对应哪个版本。
